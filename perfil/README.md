# Perfil do @franco_tecnologia

Sugestões para deixar o perfil mais atraente para quem chega. Tudo aqui a Fernanda aplica pelo app do Instagram (o Metricool não edita perfil).

## 1. Nome (campo "Nome", entra na busca)

**Franco Tecnologia | Automação contábil**

O campo nome aparece na busca do Instagram. Com "Automação contábil" ali, quem procura por isso encontra o perfil.

## 2. Bio (até 150 caracteres)

Opção A, direta (recomendada):
```
🤖 Robôs para escritórios contábeis
⏱️ Menos digitação, mais tempo para o cliente
📲 Post novo todo dia às 10h
👇 Diagnóstico gratuito de 20 min
```

Opção B, com origem:
```
Nascemos dentro de um escritório contábil 🧾
Hoje criamos robôs que tiram o trabalho repetitivo da sua equipe 🤖
👇 Diagnóstico gratuito
```

Opção C, com resultado:
```
Seu escritório gasta horas com tarefa repetitiva?
A gente automatiza: guias, notas e pendências 🤖
👇 Fale com a gente
```

## 3. Link da bio

Um link de WhatsApp com mensagem pronta, para virar conversa direto:
`https://wa.me/55DDDNUMERO?text=Oi!%20Quero%20o%20diagn%C3%B3stico%20gratuito`
(trocar DDDNUMERO pelo número comercial).

## 4. Botões de contato

Em Editar perfil, Opções de contato: ativar WhatsApp e e-mail. Aparece um botão ao lado de "Seguir".

## 5. Posts fixados (até 3)

1. **Comece aqui** (post 13, sai em 04/11): mostra com números reais o que os robôs fizeram e termina com "Mande DIAGNÓSTICO".
2. **Quanto custa o retrabalho?** (31/10): a calculadora que vira lead.
3. **5 sinais de que é hora de automatizar** (01/11): o post de mais conversa.

## 6. Destaques

Capas prontas nesta pasta (`destaque-*.jpg`, tamanho de story; o Instagram mostra só o círculo do centro):

| Capa | Nome do destaque | O que guardar |
|---|---|---|
| Oi | Comece aqui | O story do post 13 e um story curto se apresentando |
| Bot | Robôs | Prints ou vídeos curtos dos robôs funcionando (sem dados de cliente) |
| R$ | Calculadora | O story do post do retrabalho e as respostas de quem fez a conta |
| 20' | Diagnóstico | Como funciona o diagnóstico e depoimentos |
| IBS | Reforma | Os stories dos posts práticos de reforma |

Para criar: publique a imagem da capa como story, depois em "Novo destaque" escolha os stories e use a capa como imagem.

## 7. Foto de perfil

Usar o símbolo da marca, sem texto, com fundo escuro igual ao dos posts. Logo com texto fica ilegível no círculo pequeno.
