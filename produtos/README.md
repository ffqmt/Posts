# Produtos: ContAi e AUTAX

- `destaques.html` gera os stories fixos (`contai-1..3.jpg`, `autax-1..3.jpg`) e as capas dos destaques (`capa-contai.jpg`, `capa-autax.jpg`): `node produtos/exportar.mjs`.
- `contai.css` e `autax.css` são os temas de cada marca, usados nos carrosséis `post15-contai` e `post16-autax`.
- Logos: ContAi da pasta de marca do projeto; AUTAX do repositório AutaxNF (`public/`).

Destaque no perfil: depois que os 3 stories de cada produto forem publicados, no app do Instagram toque em Novo destaque, escolha os 3, use a capa correspondente e o nome "ContAi" ou "AUTAX".
